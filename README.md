
# DBMS-Mini-project
Vehicle Service Centre Management System

A DBMS project built using PostgreSQL to manage customers, vehicles, and their service records.

Features

* Store customer and vehicle details.
* Maintain vehicle service history.
* Calculate total and average service costs.
* Identify customers with high service spending.
* Generate reports using SQL queries.

Technologies Used

* PostgreSQL
* SQL
* Visual Studio Code

Concepts Used

Primary Key, Foreign Key, Constraints, JOIN, Aggregate Functions, GROUP BY, and HAVING.

Objective

To simplify vehicle service record management and track service expenses using a relational database.
